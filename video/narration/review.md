# ナレーションのレビュー記録

依頼：歴史に寄りすぎず、課題を伝えつつ、複数の AI が動的に解析していることが伝わる内容にする。
音声を作る前に 5 回レビューし、Codex CLI にもレビューを依頼する。

根拠（語りに使う事実）
- live 実行 `exp_000fbd4134b146c6b6eb`：Claude 呼び出し 17 回（see 1、extract 9、gap 1、guide 3、viewpoint 1、narrate 2）、完了まで 17.6 秒（画面の経過時間）。モデルは claude-opus-5-5。
- SAM 3（切り抜き）と Depth Anything V2（奥行き）は、Claude の読みと並行して動く（README「Performance」）。
- 判定はコード（README「Why it can be relied on」）。
- 録画 `exp_cf4ce3b056e14dd7b064`：Claude が資料不足と判断し、『幕末維新懐古談』を見つけた。

## 第1回：事実（実測と一致するか）

- 「17回呼ばれ」は live の値で正しいが、「同時に」読むのは extract の 9 回だけ。17 回すべてが並列に聞こえる。→ 回数と同時性を分けて言う。
- 「1878年、門はない」は不正確。1868 年から仮設の門があった時期がある（台本 3）。→「恒久的な門はない」に戻す。
- 「門が焼けた夜の回想録」は『幕末維新懐古談』の説明として正しい。

## 第2回：審査基準（Claude の活用 25、インパクト 30）

- Claude の判断（足りないと判断して探し直す）が 1 文に埋もれている。最大の見せ場なので独立させる。
- 公式テーマ「壁を取り払う」が語りから消えている。wall の終わりに課題を一言足す。
- 動いているのが実物だと語りで明示していない。read の冒頭で「いま動いている実際の画面」と言う。

## 第3回：感動（謎の回収）

- 冒頭で「95年」を問うのに、答えが語られない。burn か gift で回収する。
- 「門を返した人でした」の前に「95年」があると、重みが戻る。
- 締めの「いまは、次の人に届けられる」は残す。製品の説明を締めに足さない。

## 第4回：読みやすさ（v4 は 1 秒約 5 字）

- read は 16 秒の場面に対して、英語の固有名詞が続いて詰まる。Depth Anything は語りから外し「奥行きを測るAI」とする（画面が示す）。
- 「Claude」は読みの揺れを避けるため、音声では「クロード」、SAM 3 は「サムスリー」。
- 語尾の「〜ます」が続くので、体言止めを 1 か所入れる。

## 第5回：Codex CLI の独立レビュー

Codex（gpt-5.6-terra、読み取り専用）の指摘と判断。

| 指摘 | 判断 |
| --- | --- |
| 名前が刻まれているのは門ではなく提灯 | 採用（事実の誤り）。「この提灯には」に直す |
| wall と read が長い | 採用。短くし、場面も延ばす |
| 「主張から外す」は実装用語 | 採用。「事実としては採りません」 |
| 誰が読んだかが消えている | 採用。「Claudeが写真から読んだ名前は」 |
| 「外国人」を削る案 | 不採用。言葉の壁の核心 |
| 「門を返した人」を「寄進者と重なります」に | 不採用。頂点の一文を弱める。断定はコードではなく語りで、銘板と記録は社名と氏名が一致する |
| 「ほかのAIが見つけ」 | 修正して採用。切り抜きと奥行きなので「形をとらえ」 |
