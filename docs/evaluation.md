# 評価、性能、セキュリティ

アプリの画面には評価の数値を出しません（`apps/web/src/design.test.ts` で検査）。結果はここと [evaluation/results/](../evaluation/results/) にまとめます。

## 評価（`npm run eval`）

3か所の小さな手作りの評価セットです。正解は Claude Code が付けており、人の確認はこれから行います。評価の範囲は、引用の一致と、対象や時代の取り違えです。ハルシネーション全般の測定は今後の課題です。下の表は最新の結果（[2026-11-04.md](../evaluation/results/2026-11-04.md)）です。

| 方式 | Recall@10 英／日 | 対象の特定 | 関係（observed と mentions の区別） | 支持（代理指標） |
| --- | --- | --- | --- | --- |
| A 全文検索のみ | 71% / 45% | – | – | – |
| B 名前、関係の共起、RRF | 71% / 41% | 100% | – | – |
| C B に Claude の選別（プログラムの検査なし） | 60% / 46% | 95%（n=22） | 100%（n=15） | 94% |
| D B に主張と根拠の検査 | B と同じ | 100%（n=23） | 100%（n=30） | 74% |
| D+ D に探し直しを追加（採用） | 候補 74% / 61% | 100%（n=41） | 100%（n=49） | 67% |

| 除去実験 | あり | なし |
| --- | --- | --- |
| 文脈ヘッダ（Recall@10 英／日） | 71% / 41% | 63% / 41% |
| 時間の範囲：存在判定の正解率／時代の取り違え | 100% / 0 | 41% / 6（刊行年で判定した場合） |
| 関係の文脈：特定／支持（代理指標） | 100% / 74% | 100% / 72% |
| 探し直し：候補の再現率 英／日 | 74% / 61% | 71% / 50% |

そのほか：引用の原文一致 100%（n=95）、捏造した引用の拒否 4/4、存在判定 100%（n=17）、保留すべき場面の保留 100%（n=5）。

**次の課題：** 支持の指標（代理）は D+ で 67% でした。要因の切り分けは、より難しい事例を加えて検証します。存在判定の正解率は正解と同じ年表で測っているため回帰確認として扱い、刊行年で判定した場合との差を効果の指標としています。

## セキュリティ

- アクセストークンは HttpOnly、Secure、SameSite=Strict の Cookie にし、別オリジンからの変更要求は拒否します。CSP で接続先を同一オリジンに限っています（インラインスクリプトは Next.js のために許可しています）。
- Neo4j と推論サーバーは 127.0.0.1 でのみ待ち受けます。推論サーバーはトークンと入力の検証を行います。
- 写真、書籍、記録の文字列は区切ったデータとして渡し、指示に従わないよう明示します。出力はスキーマで検証します。
- モデルの重みはリビジョンを固定し、safetensors のみを使います。
- 位置情報は消し、検出した顔は端末内でぼかしてから送ります。

`npm run test:security` の結果（最終実行 2026-11-05）：vitest 17/17、推論サーバーの pytest 20/20 が成功しました。
