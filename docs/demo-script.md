# TSUMUGI デモ台本（3分・英語UI、ナレーションは日本語）

> 時間と空間を超えて、Claude が世界を紡ぐ。
> 数字は手で書かない：本番の数字は舞台裏と README（Performance・評価）から読み上げる。

## 準備

- `.env`：`CLAUDE_FAST=1`（本番だけ）、`DEMO_REPLAY_ID`＝当日朝に録った探索（ライブが失敗したら「記録を再生」）。
- 推論サーバー（SAM 3 / 深度 / SigLIP）を起動し、`/api/warm` を一度叩く（landing が自動で叩く）。
- 実機：iPhone（振動・音）、発表用 PC（`/present`、投影）。音量は小さめ、ミュートは舞台の右上。
- 予行：`scripts/rehearse.ts`、`scripts/loom-check.ts <replay> --lang en`。

| --- | --- | --- | --- |

| 0:15–0:40 | Claude が写真の文字を読む（読みと意味が流れ込む）。SAM 3 が提灯と門を切り抜き、光が輪郭をなでて浮き上がる | 「Claude が読み、手元の GPU が物を切り抜く」 | Claude の役割が見える（Claude） |
| 0:40–1:05 | 提灯に触れる：震えて、糸を弾く音と振動。左へ絹の糸（ガイド：見どころ・意味・やってみる、雷＝雨＋田）、右へ墨の糸（資料）が年の軸を通って結ばれる | 「触れると、糸がつながる。左は Claude の解説、右は原文に裏付けられた糸。混ぜない」 | 触れる体験・正直さ（インパクト） |

| 2:20–2:45 | 舞台裏：Claude の呼び出し（並列）、コードの検査、Neo4j に書いた根拠グラフ（資料→根拠→主張→年・場所）。`/notes` の旅の糸：浅草と上野が同じ資料で結ばれる | 「Claude が分解し、足りない観点を判断して探し直し、コードが確かめ、グラフに残す」 | Claude の使い方・深さ |
| 2:45–3:00 | 評価（Batch API、方式A〜D、時の判定、引用の一致、捏造引用の拒否）とセキュリティ（写真の中の指示に乗っ取られない）。締め | 「TSUMUGI は、つなぐ前に、時代・場所・言葉が本当につながるかを確かめます」 | 深さと実行力 |

## 失敗したとき

- ライブが止まった：画面の「記録を再生する（録画）」。録画であることは画面に出る。
- 推論サーバーが落ちた：切り抜きなしでも Claude の枠で触れられる（浮き上がりだけ無くなる）。
- 音が出ない：最初のタッチまで鳴らない仕様。もう一度触れる。振動は Android と iOS 18 以降のみ。
