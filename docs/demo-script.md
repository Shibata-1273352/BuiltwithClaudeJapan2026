# TSUMUGI デモ動画の構成（3分・審査は動画）

> 撮るだけで、目の前の日本が、意味と物語になる。
> 時と、場所と、人を紡ぐ。

## 物語の背骨

- **Why me**：作者は通信事業者で、人と人をつなぐ仕事をしてきた。それなのに浅草で、外国人の友人と目の前の門をつなげなかった。
- **友人の二つの問い**：「これ、なんて書いてあるの？」「いつからあるの？」。二つ目の答えが「1878年、ここに門はなかった」という驚きになる。
- **締め**：この門の前に立った人たち（イザベラ・バード、広重、荷風、高村光雲）と、いまの友人を、一本ずつ確かめた糸で紡ぐ。

## 審査基準から決めたこと

| 基準 | 見せること | 場面 |
| --- | --- | --- |
| インパクト 30% | 作者の体験。困っているのは、日本が好きな外国人と、案内する日本人。カメラアプリが答えられない二つ目の問い「いつからあるの？」に、確かめた歴史で答える | 1, 3, 6 |
| デモ 25% | 場面は6つだけ。1878年と絵の中には、それぞれ20秒以上を使う。最初の答えは英語UI（友人の視点）で見せ、全編に英語字幕を付ける | 全体 |
| Claude の活用 25% | 次の3つを、それぞれ5秒ずつ見せる（「Claude」と「コード」のチップで分ける）。①縦書きの筆文字（風雷神門、提灯の年月銘）を読む ②足りない観点を判断して、追加で探す ③今回の資料だけからネイティブ引用で答え、資料にないことは「書かれていません」と言う | 2, 5 |
| 深さと実行力 20% | 年代の判定はコードが年表で行う（Claude には判定させない）。食い違う資料は両方を出す。評価の数字は Batch API の結果から計算する | 3, 4 |

**Why Japan**（ナレーション1行）：「何度も焼けて建て直された門。日本語の資料と、外国人旅行者の英語の記録。そして、旅行者には読めない文字」。

## 台本（6場面）

秒数の目安はデモ録画（`DEMO_REPLAY_ID`）の実測による。fast mode のライブでは、写真の文字が約3秒、場所が約8秒、物語が約13秒、完了が約16秒（`e2e-sample`、ブラウザで計測）。

| 時間 | 場面 | 画面・操作 | ナレーション（日本語／英語字幕） |
| --- | --- | --- | --- |
| 0:00–0:15 | 1. 問い | 入口の「はじまり」→ 経歴の一文 | 「浅草で、外国人の友人に聞かれました。『これ、なんて書いてあるの？ いつからあるの？』。人と人をつなぐ仕事をしてきたのに、友人と目の前の門を、つなげませんでした。」 |
| 0:15–0:45 | 2. 最初の答え（Claude ①②） | EN UI のプレゼンモード（`?present=1`）で「雷門で試す」。文字が写真から浮かぶ → 最初の答え → Claude の判断の一行 | 「Claude が、縦書きの筆文字を読みます。風雷神門——風神と雷神の門。いまの門は1960年のもの。資料が足りないと Claude が判断すると、追加で探します。……では、150年前は？」 |
| 0:45–1:10 | 3. 1878年（コードの判定） | 年のつまみを1878へ。写真が夜に沈み、糸が切れる | 「1878年、イザベラ・バードはこの場所を歩きました。そのとき、雷門はなかった。判定したのは Claude ではなく、年表との照合です。」 |
| 1:10–1:30 | 4. 食い違う資料 | 時をめくる → 1866年 →「時を流す」で1960年に門が立つ | 「1866年、門は燃えた。火元と日付は、資料によって違います。違うときは、両方を出します。」 |
| 1:30–2:05 | 5. 絵の中へ と 問う（Claude ③） | 「絵の中へ」で広重の1856年に入る（カメラが門へ歩き、雪が降る）→ 戻って一つ質問 → 引用が原文に一致 → 資料にない質問で「書かれていません」 | 「広重の1856年。版画が奥行きを持ちます。質問には、今回の資料だけで答えます。資料にないことは、書かれていないと答えます。」 |
| 2:05–2:40 | 6a. 確かめられる、ということ | `/how`（Claude とコードの分担、計測値、評価）→ 3秒だけ Claude Code（デザイン規則のフックが違反を止め、Claude が同じターンで直す画面） | 「Claude に任せるのは、読む、解説する、書くこと。はい／いいえは、コードが決めます。引用の原文一致は、評価で測っています。」 |
| 2:40–3:00 | 6b. 締め | 絵はがき（2秒）→ 入口へ | 「150年前にこの門の前に立った人たちと、いまの友人を、一本ずつ確かめた糸で紡ぐ。あの日の質問に、いまは答えられます。TSUMUGI。」 |

入れないもの：言の地層（前提知識が要る）、海を越える糸、金閣寺。金閣寺は、6a の字幕一行（「資料のない場所でも、読みとガイドは使えます」）で触れる。

## 撮影の手順

- 1920×1080 または 3840×2160 で撮る。舞台は `?present=1`（4K でも比例して拡大される）。プレゼンモードでは、資料数・糸の数と資料の種類のタグ列を隠し、経過時間だけを出す。
- 事前：推論サーバーを起動し、入口を一度開いて温める（モデルは30分保持）。旅ノートの参考訳は一度開いて作っておく（キャッシュされる）。`CLAUDE_FAST=1` はライブ撮影のときだけ使う。
- 録画の再生：`/replay/<DEMO_REPLAY_ID>`（Claude は呼ばない。録画であることは画面に出る）。
- 予行：`scripts/acceptance.ts <base> <replay> <scene>`、4K の確認は `scripts/shots-4k.ts`、絵の中の GPU での確認は `scripts/space-probe.ts`。
- 音：糸を弾く音は最初のタッチから鳴る。ナレーションと重ねるなら「音：切」にする。

## 失敗したとき

- ライブが止まった：「記録を再生する（録画）」。
- 推論サーバーが落ちた：切り抜きなしでも Claude の枠で触れられる。3D は 2D 表示になる（「3Dで見る」で戻せる）。
