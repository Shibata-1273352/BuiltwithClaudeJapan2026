# TSUMUGI デモ動画の構成（3分・審査は動画）

> 撮るだけで、目の前の日本が、意味と物語になる。

## 審査基準から決めたこと

| 基準 | この動画で見せること | 場面 |
| --- | --- | --- |
| インパクト 30% | 作者自身の体験から始まる。困っている人は「日本が好きな外国人と、案内する日本人」。ハッカソン後も現地で使い続ける形（どこでも読みとガイド、旅ノート、絵はがき） | 0:00, 2:30, 2:50 |
| デモ 25% | 冒頭12秒で「誰の・どんな課題を・どう解くか」。前提知識なしで、操作の流れだけで価値が分かる。冒頭で投げた問い（いつからあるの？）を途中で回収し、最後まで見たくなる | 0:00–1:25 |
| Claude の活用 25% | 画像を読む／文化を解説する／足りない観点を判断して探し直す／ネイティブ引用で答える、をコードの判定と分けて見せる。Claude Code（計画・サブエージェント・スキル・フック）は実物を見せる | 0:20, 1:55, 2:35 |
| 深さと実行力 20% | 年代はコードが年表で判定、引用は原文と照合、資料にないことは「書かれていません」。評価の数字（Batch API）。食い違う資料は両方を出す | 1:00, 2:35 |

物語の背骨は一本だけにする：**友人の二つの問い**。「これ、なんて書いてあるの？」「いつからあるの？」。二つ目の答えが「150年前、ここに門はなかった」という驚きにつながる。

## 台本

秒数の目安は、デモ録画（`DEMO_REPLAY_ID`）の実測に合わせてある。fast mode のライブでは、写真の文字が約3秒で流れ始め、場所が約8秒、物語が約13秒、完了が約18秒（ブラウザで計測）。

| 時間 | 画面 | 操作 | ナレーション（要旨） |
| --- | --- | --- | --- |
| 0:00–0:12 | 入口の「はじまり」 | 静止 | 「浅草で、外国人の友人に聞かれました。『これ、なんて書いてあるの？　いつからあるの？』——答えられませんでした。」 |
| 0:12–0:20 | 入口の見出し | 「雷門で試す」を押す（または実機で「カメラで撮る」） | 「TSUMUGI は、撮るだけで、目の前の日本を意味と物語にします。」 |
| 0:20–0:35 | 舞台：最初の答え | 待つだけ | 「Claude が写真の字を読みます。風雷神門——風神と雷神の門。そして、いつからあるのか。いまの門は1960年のもの。……では、150年前は？」（問いを残す） |
| 0:35–0:55 | 舞台：触れる | 提灯に触れる → タップ | 「触れると、震えて、糸が鳴る。見どころ、意味、やってみること。雷は、雨と田。Claude の解説と、資料の糸は、線の種類で分けています。」 |
| 0:55–1:10 | 舞台：年のつまみ | つまみを1878へ | 「1878年。写真が夜に沈み、門は影になり、その年の糸が切れる。イザベラ・バードが歩いた浅草に、雷門はなかった。判定したのは Claude ではなく、年表との照合です。」（問いの回収） |
| 1:10–1:25 | 時をめくる（パネル） | 「時を流す」 | 「1866年、門は燃えた——資料が食い違うときは、両方を出します。1960年、門は立ち上がる。」 |
| 1:25–1:40 | 言の地層 | バードの「Ni-ô」に触れる | 「バードが見た“赤い門”は、雷門ではなく、雪の奥の仁王門でした。」 |
| 1:40–1:55 | 絵の中へ | 版画の中へ、マウスで傾ける | 「広重の1856年。版画が奥行きを持ち、雪が降る。」 |
| 1:55–2:10 | 糸を引く | 候補の質問を押す／自分で聞く | 「質問には、今回の資料だけで答えます。引用は原文と照合し、資料にないことは『書かれていません』。」 |
| 2:10–2:25 | 絵はがき・海を越える糸 | 「絵はがきを作る」 | 「確かめた一文を、絵はがきに。資料は、ニューヨークのメトロポリタン美術館や、英国ヨークシャー生まれの旅行者から届いています。」 |
| 2:25–2:35 | どこでも（金閣寺） | 自分の写真を送る | 「資料のない場所でも、字の読みとガイドは使えます。歴史は、確かめられる場所でだけ語ります。」 |
| 2:35–2:50 | しくみ・舞台裏 | `/how` → 舞台裏の根拠グラフ | 「Claude に任せるのは読む・解説する・書くこと。はい／いいえはコードが決める。評価は Batch API で、引用の原文一致はこの数字。開発は Claude Code で——計画、サブエージェントの批評、検証のスキル、デザイン規則のフック。」 |
| 2:50–3:00 | 入口へ戻る | 静止 | 「あの日の質問に、いまは答えられます。TSUMUGI。」 |

## 撮影の手順

- 画面：1920×1080。動画では文字が小さく見えるので、舞台は `?present=1`（プレゼンモード）で撮る。4K で撮る場合もそのまま比例して拡大される。
- 事前：推論サーバーを起動し、入口を一度開いて温める（モデルは30分保持）。`CLAUDE_FAST=1` はライブ撮影のときだけ。
- 録画の再生：`/replay/<DEMO_REPLAY_ID>`（Claude の呼び出しなし、録画であることは画面に出る）。
- 予行：`scripts/rehearse.ts`、`scripts/loom-check.ts <base> <replay> --lang en`、`scripts/time-shot.ts`、`scripts/names-shot.ts`、`scripts/space-shot.ts`。
- 音：糸を弾く音は最初のタッチから鳴る。ナレーションと重ねるなら「音：切」。

## 失敗したとき

- ライブが止まった：「記録を再生する（録画）」。
- 推論サーバーが落ちた：切り抜きなしでも Claude の枠で触れられる。3D は 2D 表示になる（「3Dで見る」で戻せる）。
- 文字が小さい：プレゼンモード（P キー）。
