# 視覚で探す（FR-58、P1）：提灯から提灯へ

受け入れ条件：大提灯の切り抜きで、提灯を描いた浮世絵が上位5件に入る。

## 仕組み

1. **問い合わせ**：写真から SAM 3 が切り抜いた大提灯。
2. **ギャラリー**：歌川広重《名所江戸百景》118点。Wikimedia Commons から、作品ごとにパブリックドメインの画像を1点ずつ集めた（`corpus/visual-gallery.json`）。
   - The Met のAPIは、この作業中にボット対策で403を返すようになった。回避はせず、取得元を Commons に切り替えた。
3. **索引**：版画1点ごとに、全体、2×2・3×3の重なりのあるタイル、SAM 3 が見つけた版画内の提灯を、画像埋め込みにする。
4. **検索**：版画の得点は、問い合わせと最もよく似た切り出しの類似度。
5. **画面**：上位5件を「似た図像（画像の類似度。根拠ではありません）」として表示する。一致した部分を枠で示す。主張や糸にはしない。

## 試したこと（正解：《浅草金龍山》。目で確かめた大提灯の作品）

| 構成 | 《浅草金龍山》の順位（118点中） |
| --- | --- |
| SigLIP base 224、切り抜きの矩形のまま | 21位 |
| 同上、マスクを白い背景に置く／灰色の背景に置く | 47位／54位 |
| 同上、「視る」の段階のラベル（giant red paper lantern）の文字だけ／画像と文字の両方 | 12位／13位 |
| **SigLIP so400m 384（fp16）**、矩形のまま | **1位**（類似度0.68。2位は0.65） |

- **問い合わせ**：同じ写真から作った3件で、すべて1位。元の CC0 写真と、アップロードして顔をぼかした2件です。いずれも同じ1枚の写真なので、独立した3件ではありません。
- **so400m**：メモリは fp16 で1.8GB（fp32 なら3.5GB）。順位は fp32 と同じ。1回の検索は0.6秒。
- **使わなかった日本向けモデル**：
  - rinna/japanese-clip と SigLIP 2：使えるが、so400m で条件を満たしたため試していない。
  - LINE clip-japanese-base：提供元のコードの実行（`trust_remote_code`）が必要で、方針（ASI04）に反する。
  - Stability Japanese Stable CLIP：独自ライセンスかつ承認制。

## SAM 3 で版画の中の提灯を切り抜く

- **プロンプトの違い**：「paper lantern」で見つかるのは小さな提灯（11点）。《浅草金龍山》の大提灯は「paper lantern」では0.1前後で見つからず、「large red lantern」で0.69になった。
- **限界**：「large red lantern」は、その版画を見てから選んだ言葉。デモの例に合わせた調整になっているので、他の写真での一般性は確かめていない。

## 限界

- 正解は1点、問い合わせは事実上1枚の写真。受け入れ条件の確認であって、精度の評価ではない。
- 類似度は根拠ではない。広重が雷門の大提灯を描いたことは、別の根拠（浅草寺公式「寛政の雷門は…広重…の好画題」、The Met 56689）で示している。
